# MiniCade Privacy Policy Website

This repository contains the official static website for the MiniCade Privacy Policy.
It is designed to be hosted seamlessly on GitHub Pages.

## Features

- **Modern & Responsive:** Built with Semantic HTML5 and Vanilla CSS. No frameworks, no bloat.
- **Dark Theme:** Perfectly matches the MiniCade branding and aesthetic.
- **Easy Updates:** The `index.html` file contains obvious `TODO` markers so updating the legal copy is straightforward.
- **GitHub Pages Ready:** Drop-in ready for deployment.

## Local Development

No build steps or dependencies are required. 
Simply open `index.html` in your web browser to preview the site.

## Deployment to GitHub Pages

To publish this website on GitHub Pages:

1. Push all files in this directory to a GitHub repository (e.g., `minicade-privacy-policy`).
2. Go to your repository's **Settings** on GitHub.
3. In the left sidebar, click on **Pages**.
4. Under "Build and deployment", set the **Source** to `Deploy from a branch`.
5. Under **Branch**, select the `main` (or `master`) branch and the `/ (root)` folder.
6. Click **Save**.

Your site will typically be live within minutes at: 
`https://[your-username].github.io/[your-repo-name]/`
